# Batch 07 — ph_* PluginHost factories A–G

Auditor #7. Branch: `claude/fix-recording-studio`. Scope: ~37 ph_* plugins
A–G alphabetically, audited per the 8-bug-class spec in `00_audit_spec.md`.

PluginHost UI is auto-generated from `registry.js` `params` array (see
`PluginHost.js` lines 274–319 for `addPlugin`, factory map at 125+, and
`setParam` at 355). Knob ids equal `params[i].id`; mismatch with the
factory's `setParam(k,…)` switch = silent dead knob.

`COMPONENT_MAP` (bug class 8) = N/A for ph_* plugins (their UI is the
auto knob grid, not an SPX window).

---

### 1. AICompressor (`a_i_compressor`)
- **UI file:** auto-generated by PluginHost from registry params (threshold, ratio, attack, release, makeup, style)
- **Factory:** `src/front/js/component/audio/plugins/plugins/AICompressorPlugin.js:5`
- **1. Param names:** ❌ — UI sends `attack`, `release`, `style` but factory `setParam` only handles `threshold`, `ratio`, `makeup` (line 13). `attack`/`release`/`style` are silent dead knobs.
- **2. Units:** ❌ — registry `attack`/`release` are in `ms` (0.1–200 ms / 10–2000 ms). Factory init uses `comp.attack.value=0.003` (seconds), `release=0.1`. If setParam ever handled them it would also need /1000. Default `attack` fed as 10 (registry default in ms) but factory hard-codes 0.003 s. Initial defaults applied to compressor are wrong if registry default ever flows in (line 9 ignores `p.attack`/`p.release`).
- **3. Missing cases:** ❌ — `attack`, `release`, `style` declared in registry, none in switch.
- **4. Worklets:** N/A — no AudioWorkletNode.
- **5. Topology:** ✅ input→comp→makeup→output (line 11).
- **6. Dispose:** ⚠️ — only exposes `disconnect()` on output; no real `destroy()`. PluginHost.removePlugin (line 334) calls `inst.destroy()` but factory only returns `disconnect`. Compressor + makeup nodes leak per remove.
- **7. Defaults:** ⚠️ — `makeup` factory default 3 dB (line 10) vs registry default 0 dB. On insert the plugin adds +3 dB make-up gain — not neutral.
- **8. COMPONENT_MAP:** N/A
- **Severity:** P0
- **Demo-blocker?:** yes (3 of 6 knobs do nothing)

## Batch 07 Summary

- **Total audited:** 45 ph_* plugins (A through G alphabetically — full slice)
- **Clean:** 4 (Compressor, EQ3Band, Gain, plus partial credit to Flanger)
- **P2 (cosmetic):** 1 (Flanger — works, only dispose nit)
- **P1 (polish):** 5 (CombFilter, DCFilter, Gate, Expander, AutoPan, BassEnhancer, DustScratch)
- **P0 (demo-blocker):** 35
- **Top 5 worst plugins:**
  1. **AutoTune** — fake plugin, no actual pitch correction (just a delay+lowpass), 4/5 knobs dead, analyzer orphan
  2. **GraphicEQ4Band/5Band/6Band** (tied) — factory files exist and look correct but are NEVER imported by `PluginHost.js`; calling `addPlugin('graphic_e_q4_band')` throws. **Whole plugin family non-functional.**
  3. **Cassette** — registry params `drive/noise/hfLoss/mix` have ZERO overlap with factory's `tone/hiss`; constant hiss osc and tanh saturation always on
  4. **Fuzz** — default 50× pre-gain into hard-clip curve = catastrophic distortion on insert; 4/5 knobs dead
  5. **FrequencyShifter** — wrong concept (it's a ring mod, not freq shift); default settings MUTE the audio
- **Common patterns:**
  - **Param name divergence is endemic.** Registry uses one set of ids; factories were written against a different set. ~35/45 plugins have at least one dead UI knob; many have ALL knobs dead.
  - **`destroy()` missing** in 90 % of factories. PluginHost.removePlugin (line 334) calls `inst.destroy()`; factories only export `disconnect()` — so OscillatorNodes, setIntervals, ScriptProcessors, AudioBufferSources all leak per insert/remove cycle.
  - **`mix` parameter rarely implemented** even when in registry — most factories hard-code 100 % wet or have no dry path.
  - **setInterval-based detectors** (BreathGate, DynamicEQ, EnvelopeFilter, Gate, Expander) at 25 ms produce zipper noise and don't release on plugin removal.
  - **Multi-plugin source files** (DynamicEQPlugin.js holds 25+ factories; AirEQPlugin.js holds 22+) cause confusion — duplicate `createXyzPlugin` exports never imported. Recommend cleanup so each factory lives in one file.
  - **GraphicEQ family broken at the registration level** — 3 plugins entirely non-functional from the host's point of view.
  - **Compressor and Gain are exemplary** — they correctly use unit conversion, try/catch around AudioWorkletNode, and a real `destroy()`. Use them as the template for fixing the rest.
